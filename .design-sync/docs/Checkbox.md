# Checkbox

Round 18px checkbox (Spec v2): a 1.5px `--check-border` ring when unchecked; checked fills with ink and shows a white check. It is a native `<input type="checkbox">` restyled, so labels, forms and keyboard work as usual. `accentColor` changes the checked fill (defaults to `var(--ink)`).

The dominant composition is a task row: stripe, checkbox, then title, with completed rows struck through in `--ink-faint`.
