# Checkbox

18px square checkbox with a 6px radius (Spec v3): a 1.5px `--check-border` edge when unchecked; checked fills with ink and shows a white check. It is a native `<input type="checkbox">` restyled, so labels, forms and keyboard work as usual. `accentColor` changes the checked fill (defaults to `var(--ink)`).

Pass `round` when it completes a **task** — task completion is a circle, so a checklist and a task list read differently. Checked checklist labels are struck through in `--ink-faint`.
