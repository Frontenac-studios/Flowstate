# GhostCategoryStrip

The life-area legend at reduced opacity — pre-data chrome (D10). One equal segment per `PROJECT_CATEGORIES` entry (business blue, personal purple), `role="img"` with a default label.

`opacity` conventions: ~0.45 for D10 chrome, ~0.35 in week columns. It fills whatever width the caller gives it.
