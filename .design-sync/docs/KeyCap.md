# KeyCap

A keyboard hint rendered as a visible pill cap: `--surface-2`, hairline border, caption size (D38 / V5). Inside a primary `Button` or a dark `Tooltip` it inverts to a translucent chip automatically.

Chords are **one cap, not three** — pass the whole string (`⌘⇧K`). Caps sit on the baseline inside running copy.
