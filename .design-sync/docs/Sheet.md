# Sheet

Spec v3 Sa sheet: docked to the right edge, full height, 340–440px (`width`, default 420), **no radius**, `--shadow-sheet` over the 32% `--scrim`. Header: an optional `breadcrumb` (a project dot + "Project › Phase" in 13px muted), a 20/600 `title`, and a close ×. The body scrolls; the `footer` sits behind a 1px divider with the secondary action on the left and the primary on the right.

Use it for task detail and other object detail; use `Dialog` for a decision.
