# Switch

Spec v3 Cc on/off toggle: a 36×22 pill track (off `#d5d8dd`, on ink) with an 18px white knob. A real `role="switch"` button, controlled via `checked` + `onCheckedChange`. Label it with `aria-label` or an adjacent label.

Use it for a single on/off **setting**; use `Checkbox` for choosing items in a list.
