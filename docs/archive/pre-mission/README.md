# Pre-mission archive

These documents describe **Kash 3.0 / 3.1** — a whole-life planning app with a wellness
garden, a bingo goal board, a values system and a daily-wins tracker.

Flowstate stopped building that product in August 2026. `MISSION.md` in the repo root is the
product now; `docs/v1-scope.md` is the plan. Nothing in this folder is authoritative, and
`build-status.md`'s "Kash 3.1 nearly complete" refers to a product that is being torn down.

They are kept only as a record of why things were built the way they were. **Do not plan,
estimate, or check off work from anything in here.**

Three documents were deliberately kept out of the archive because they are still live:

- `docs/design-tokens.md` (was `kash-3.0-design-tokens.md`) — the design system in use.
- `docs/rls-audit.md` — current security posture.
- `docs/audits/2026-07-05-e2e-flow-audit.md` — the audit method, still reusable.
