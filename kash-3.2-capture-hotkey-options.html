Global capture: what the key press does

Three ways to answer one question — when you hit the hotkey while you are in Gmail, what appears? Same shortcut, same data, same tRPC call underneath. Only the surface differs.

First, the mechanic

A global shortcut is registered with macOS, not with the app

Every shortcut Flowstate has today is a keydown listener inside the web page. ⌘⇧A opens quick-capture only when a Flowstate window is the front app — press it in Gmail and Gmail gets the keystroke. That is the whole gap: not that capture is missing, but that it is unreachable from where you actually are when you think of the thing.

A global shortcut is different in kind. The Rust shell asks macOS to reserve ⌘⇧K system-wide. The OS then intercepts that combination before any app sees it and wakes Flowstate instead. Three consequences worth knowing: the reservation is exclusive (if another app already holds the combo, registration fails quietly, which is why a rebind field in Settings matters); it only works while Flowstate is running, which is why launch-at-login is this feature's twin; and macOS will ask you to grant the app permission the first time.
