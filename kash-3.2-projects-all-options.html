Eight decisions, every option drawn. Nothing here is chosen — earlier picks are reopened. Where I have a view I've put it in a marked box at the end of the section, clearly as an opinion rather than a default.

Decision two

Planning a project

Since a project starts as an empty container, planning is a thing you do later, sometimes days later. It needs a front door that is always open, not a wizard that only appears in the ten seconds after creation.

Decision four

The composer's future

Current grammar: title ; due ; priority ; phase path, with ;;; for phase-only lines. Documented in one chip you must click. Three surfaces teach two different submit keys. The tags editor tells you to use ;tag, which the parser reads as a due date and rejects. Bare lines file into the last phase you drilled into, which is never named and which changes when you resize the window.

A queue that never empties is just a third pile wearing a different hat.
